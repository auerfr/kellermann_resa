1. Le tableau de bord

C'est la première page que vous voyez en arrivant. Elle est organisée du plus urgent au moins urgent :

  1. 🔔 Notifications de couverts (bandeau jaune en haut) — Une loge a envoyé un nombre de couverts. Lisez-le, puis cliquez ✓ Lu pour l'archiver.
  2. 🔒 Fermetures (bandeaux rouges) — Les périodes de fermeture que vous avez saisies.
  3. Aujourd'hui — Les repas du jour, avec les couverts mis en évidence.
  4. Cette semaine (fond bleu) — Les 7 prochains jours pour anticiper vos courses.
  5. La suite — Les tenues au-delà de la semaine, jusqu'à fin d'année.

3 boutons d'action principaux :

  • 📋 Imprimer le planning — Génère le planning complet jusqu'à fin d'année, prêt à imprimer.
  • 👥 Saisir les couverts — Pour noter le nombre de couverts d'une loge.
  • 🔒 Fermeture — Pour bloquer une période (congés, fermeture, travaux…).
2. Le calendrier

Le calendrier est accessible depuis Tableau de bord → 📅 Calendrier complet.

  • Sur mobile : vue agenda chronologique, un événement par carte.
  • Sur desktop : vue grille mensuelle + tableau récapitulatif en dessous.

Navigation : utilisez les flèches ‹ › ou le sélecteur de mois pour naviguer. Le filtre Agapes n'affiche que les tenues avec agapes confirmées ; Blocages isole les créneaux bloqués.

Cliquer sur un événement ouvre une fiche détaillée (loge, salle, couverts, contact, statut).

3. Code couleur
Vert — Agapes confirmées

La loge a explicitement confirmé avoir des agapes. Le traiteur doit préparer un repas.

Violet — Agapes classiques probables

Tenue récurrente du soir (≥ 18h) — cette loge a des agapes classiques selon son rythme habituel. À confirmer.

Jaune — Tenue du soir probable

Tenue exceptionnelle débutant après 18h. Des agapes sont possibles mais non confirmées.

Ambre — Banquet d'ordre

Réservation d'une salle d'agapes (Les Gobelets, L'Oie et le Grill) pour un banquet rituel. Le nombre de couverts est précisé.

Émeraude — Salle agapes

Salle d'agapes réservée via le portail (hors banquet d'ordre explicite).

Rouge — Créneau bloqué

Aucune réservation possible pendant cette période. Peut couvrir plusieurs jours.

4. Les agapes

Les agapes sont le repas servi après une tenue maçonnique au temple. Il en existe deux types principaux :

  • Agapes confirmées (vert) : la loge a coché "Besoin d'agapes" lors de sa réservation. Le nombre de couverts est soit renseigné directement, soit transmis via une notification de couverts.
  • Agapes classiques probables (violet) : tenue récurrente de soir — cette loge fait habituellement des agapes classiques à la même heure chaque semaine/quinzaine. Le chiffre de couverts peut être estimé d'après l'historique de la loge.
  • Soir probable (jaune) : tenue exceptionnelle en soirée dont les agapes ne sont pas encore confirmées.
💡 Bon à savoir — Les agapes classiques ont lieu entre 22h et 23h environ, à la suite de la tenue. Le traiteur doit avoir les plats prêts pour cette heure, même si la loge n'a pas encore confirmé par écrit.
5. Les banquets d'ordre

Un banquet d'ordre est un repas ritualisé qui occupe une salle d'agapes dédiée. Il se distingue des agapes de tenue car :

  • Il est réservé explicitement via une demande de salle de type Banquet.
  • Il se déroule dans Les Gobelets et les Raisins (petits comités) ou L'Oie et le Grill (grandes assemblées, congrès).
  • Il débute généralement aux mêmes horaires qu'une tenue de soirée (19h–20h) et dure 2 à 3 heures.
  • Le nombre de couverts est indiqué à la réservation.
⚠ Attention — Un banquet d'ordre le même soir qu'une tenue temple peut signifier que les frères participent aux deux événements. Vérifiez la salle réservée pour éviter tout conflit logistique.
6. Gérer les couverts

Deux manières de connaître le nombre de couverts :

  1. Notification de couverts — Les loges peuvent envoyer une notification via leur portail. Elle apparaît en bandeau orange sur le tableau de bord. Après lecture, marquez-la Lu.
  2. Page Couverts loges (👥 Couverts loges) — Permet de saisir directement le nombre de couverts pour une loge, une date et une heure données, depuis l'espace traiteur.

Les couverts estimés (tilde ~) proviennent de l'historique de la loge. Les couverts confirmés (sans tilde) ont été explicitement renseignés.

7. Bloquer un créneau

Pour empêcher toute réservation sur une période donnée (fermeture, maintenance, congés…) :

  1. Cliquez sur 🔒 Bloquer dans le tableau de bord ou le calendrier.
  2. Renseignez la date de début et, si nécessaire, la date de fin (le blocage couvre tous les jours de la période).
  3. Précisez les horaires et les salles concernées.
  4. Ajoutez un motif explicite (ex : "Fermeture estivale", "Travaux cuisine").

Le blocage apparaît en rouge sur le calendrier pour tous les jours de la période. Il peut être supprimé à tout moment depuis la page Blocages.

8. Export et états des lieux

Deux outils pour extraire les données :

  • 📋 État des lieux jusqu'en fin d'année (accéder) — Tableau complet de toutes les tenues et banquets à venir jusqu'au 31 décembre, groupé par mois. Inclut un bouton Export Excel et Imprimer.
  • 📥 Export Excel (depuis le Planning mensuel) — Permet de télécharger un fichier Excel sur une période et un type de données au choix (agapes confirmées, tenues soir, banquets, ou tout). Inclut les contacts de chaque loge.

Pour générer un PDF imprimable : utilisez le bouton 🖨 Imprimer et sélectionnez "Enregistrer en PDF" dans la boîte de dialogue d'impression de votre navigateur.
